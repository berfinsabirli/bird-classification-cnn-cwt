# Bird Species Classification Using CNNs

## Overview

This project explores bird species classification using
Convolutional Neural Networks (CNNs) and audio-derived spectrograms.

It also investigates a wavelet-based approach and compares it
with the standard spectrogram-based method.

## Methods

- Audio representation using spectrograms
- Convolutional Neural Networks (CNNs)
- Wavelet-based feature representation
- Comparative model experiments

## Notebooks

- `birdsclassification.ipynb`: CNN-based bird classification.
- `birdsclassification_with_wavelet_fixed.ipynb`:
  Wavelet-based classification experiments.

## Dataset

The project uses audio-derived data and processed spectrograms.
Large datasets and generated files are not included in this repository.

## Technologies

- Python
- TensorFlow / Keras
- Jupyter Notebook
- Audio signal processing
- Deep learning
